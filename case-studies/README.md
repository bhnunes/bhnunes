# Selected AI and machine learning work

These projects connect my software engineering experience with applied AI and reproducible machine learning research.

## Reproducible pathology ML pipeline

My master's research at UNICAMP focused on binary segmentation of prostate cancer in histopathological images. I developed a workflow spanning data preparation and quality control, patient-level partitioning, model training, ensemble optimization and evaluation. Supporting artifacts record configurations, data provenance and experimental outputs.

The repository provides the implementation and reproduction documentation. The DIAGSET deposit contains generated research metadata and experimental artifacts; the original publicly available DIAGSET images are not redistributed. This is research work, with no claim of clinical deployment.

[Repository and documentation](https://github.com/bhnunes/Master_Coding) · [Reproducibility artifacts](https://doi.org/10.25824/redu/EDPCF2)

## SDLC Run Insights Chatbot

At IBM, I architected and developed a production-deployed chatbot for questions about selected software lifecycle runs. My work included a Python/FastAPI service, retrieval of run evidence and platform knowledge, IBM watsonx LLM integration, guardrails, observability, automated tests and deployment support.

[Read the public case study](sdlc-run-insights-chatbot.md). Source code is not public.
