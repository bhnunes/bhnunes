# SDLC Run Insights Chatbot

**Context:** Professional project at IBM, August 2026–present.  
**Status:** Production-deployed. Source code is not public.

## Purpose

The chatbot answers questions about selected software lifecycle runs. It retrieves run evidence and platform knowledge and uses IBM watsonx large language models to generate grounded responses.

## My contribution

I architected and developed the chatbot, including a Python/FastAPI service that retrieves the relevant evidence and knowledge, classifies questions and generates responses through IBM watsonx LLMs.

I implemented prompt-injection and output-safety guardrails, observability and automated tests, and contributed production deployment support.

## What this demonstrates

The project connects application architecture and API development with retrieval-augmented generation. It also includes engineering work around model behavior: input and output safeguards, observability, automated testing and production deployment support.
